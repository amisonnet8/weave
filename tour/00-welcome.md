## Weaveとは何か

Weaveは動的型付けのプログラミング言語です。他の多くの言語が「関数呼び出し」「オブジェクトのメソッド呼び出し(継承込み)」「並行プロセス間の通信」を3つの別々の仕組みとして持っているのに対し、Weaveはこの3つを**1つの仕組み**の上に統一します。

1. オブジェクト`obj`のプロパティ`x`を読む(`obj.x`)
2. プロトタイプを継承したオブジェクトが、親の持つ関数`greet`を呼ぶ(`obj.greet()`)
3. アクター`a`に`"increment"`というメッセージを送る(`send(a)("increment")(5)`)

この3つは、実装レベルでは「オブジェクト(map)に対して名前で検索し、見つかった値を使う」という**同じ処理**でしかありません。アクターへのメッセージ送信は、「アクターが持つ内部オブジェクトから、メッセージ名と同じ名前のプロパティ(関数)をプロトタイプチェーン経由で検索し、`self`と引数を渡して呼び出す」という、メソッド呼び出しそのものです。このツアーでは、3章(オブジェクトとプロトタイプ)と5章(アクターモデル)の両方で、この統一原理が実際にどう現れるかを見ていきます(`weave_spec.md` §0)。

Weaveは動的型付け言語です。変数に型注釈は書かず、値は実行時まで数値・文字列・真偽値・`nil`・オブジェクト・関数・アクター参照のどれになるか分かりません(2章で詳しく扱います)。

## Hello, Weave

`hello.weave`という名前で、次の内容のファイルを作ります。

```weave
main = fn(args) {
	print("Hello, Weave!")
	return 0
}
```

`main`は専用の構文ではなく、他のどんな関数定義とも見た目が全く同じ、予約された名前への代入です(`weave_spec.md` §12)。プログラムの唯一の入口で、コマンドライン引数のリストを1つの引数(ここでは`args`という名前にしていますが、何と名付けてもかまいません)として受け取り、数値の終了コードを返します。

実行するには次のようにします。

```sh
$ weave run hello.weave
Hello, Weave!
```

`weave run`は「コンパイルして即座に実行する」コマンドです。`weave build`で実行ファイルを作ることもできます(詳しいコマンド一覧は[`../README_ja.md`](../README_ja.md)を参照)。
