## 値と型(`weave_spec.md` §2)

Weaveは**動的型付け**言語です。変数宣言に型注釈は書きません。値は次の6種類のいずれかです。

| 種類 | 例 | 備考 |
|---|---|---|
| 数値 | `1`, `-3`, `1.5` | 整数・浮動小数点を区別しない(内部的には常にfloat64相当) |
| 文字列 | `"hello"` | |
| 真偽値 | `true`, `false` | |
| `nil` | `nil` | 「値が無い」を表す唯一の値 |
| オブジェクト | `{ x: 1, y: 2 }` | 3章で扱う |
| 関数 | `fn(a) { ... }` | 2章で扱う |
| アクター参照 | (`spawn(...)`の戻り値) | 5章で扱う |

すべての変数は宣言時にゼロ値を持たず、代入されるまで`nil`です。

```weave
main = fn(args) {
	x = 1
	y = "hello"
	z = true
	w = nil
	n = 3.5
	print(x)
	print(y)
	print(z)
	print(w)
	print(n)
	return 0
}
```

数値リテラルは10進以外に、16進(`0x1A`)・8進(`0o17`)・2進(`0b101`)でも書けます。桁区切りの`_`(`1_000_000`)もどの形にも使えます(`weave_spec.md` §1.0)。どの書き方で書いても内部的には同じfloat64の値になり、実行時に元の書き方による違いは残りません——`0xFF`と`255`は完全に同じ値です。指数表記(`1e10`)・先頭が`.`で始まる小数(`.5`)は書けません(§18.1)。

```weave
print(0x1A)      // 26
print(0o17)       // 15
print(0b101)        // 5
print(1_000_000)     // 1e+06(=1000000)
```

**「真偽値として扱えるのは`true`/`false`だけ」という制約が厳格に適用されます。** JavaScriptの`if (0)`やPythonの`if []`のような、真偽値以外の値が自動的にtruthy/falsyへ変換される仕組みはWeaveにはありません。`if`/`while`の条件式、`&&`/`||`の両オペランドは、実際に`true`/`false`でなければ実行時エラーになります。

```weave
if 5 {}   // 実行時エラー: 条件は真偽値でなければならない
```

## 変数と代入(`weave_spec.md` §10)

代入は`=`で行います。複合代入・インクリメント演算子(`+=`・`++`等)はありません——`i = i + 1`と書きます。

Weaveのスコープは`{ }`で作られるブロック単位です。内側のブロックで外側と同じ名前へ代入すると、**新しい変数を作るのではなく、既存の変数を再代入します**。どこにも見えていない名前への代入だけが、そのブロック内だけの新しい変数になります。

```weave
x = 1
if true {
	x = 2   // 再代入(xは既に外側で見えている)
}
print(x)   // 2

if true {
	y = 3   // yはここで初めて見える名前 -> このifブロック内だけのローカル変数
}
print(y)   // コンパイルエラー: yは未定義
```

この規則がないと、`while i < 10 { i = i + 1 }`のようなループのカウンタ更新が、外側の`i`ではなく毎回新しい`i`を作ってしまい、条件式の`i`が永遠に更新されません(無限ループになります)。

## 演算子(`weave_spec.md` §8)

```
+   -   *   /   %        算術演算子(数値のみ。+は文字列結合にも使う)
==  !=                    等価比較
<   <=   >   >=           順序比較(数値・文字列)
&&  ||  !                 論理演算(真偽値)
```

```weave
main = fn(args) {
	print(1 + 2 * 3)         // 7(掛け算が先)
	print((1 + 2) * 3)       // 9
	print("foo" + "bar")     // "foobar"
	print(10 % 3)             // 1
	print(1 == 1.0)           // true
	print(1 == "1")           // false(型が違うだけ、エラーにはならない)
	print("abc" < "abd")      // true(文字列も順序比較できる)
	return 0
}
```

**数値は常にfloat64相当なので、`0`除算はエラーになりません。** `1 / 0`は`+Inf`、`0 / 0`は`NaN`になります(IEEE754の浮動小数点規則にそのまま従います)。`%`も整数専用ではなく浮動小数点の剰余なので、`5.5 % 2`のような計算もできます。

優先順位は上から`( )`/`.`/呼び出し/`[ ]` → 単項`!`・単項`-` → `* / %` → `+ -` → `< <= > >=` → `== !=` → `&&` → `||`(最低)の順です。

## 制御構文(`weave_spec.md` §7)

`if`/`elif`/`else`と`while`は、他の多くの言語と同じ形です(`for`は少し特殊なので4章で扱います)。

```weave
main = fn(args) {
	x = 100
	if x == 100 {
		print("hundred")
	} elif x == 200 {
		print("two hundred")
	} else {
		print("other")
	}

	i = 0
	while i < 10 {
		i = i + 1
	}
	print(i)   // 10

	return 0
}
```

`break`/`continue`は最も内側のループにのみ作用します(関数の中に入れ子で定義した別の関数リテラルの内側からは`break`できません——詳しくは2章で扱います)。

## 演習

1. `celsius = 30`から華氏温度(`celsius * 9 / 5 + 32`)を計算して`print`するプログラムを書いてください。
2. `1`から`20`までの数のうち、3の倍数のときは`"Fizz"`、5の倍数のときは`"Buzz"`、両方の倍数のときは`"FizzBuzz"`、それ以外はその数自身を`print`する(いわゆるFizzBuzz)プログラムを、`while`だけを使って書いてください。

<details>
<summary>解答例</summary>

```weave
main = fn(args) {
	celsius = 30
	fahrenheit = celsius * 9 / 5 + 32
	print(fahrenheit)
	return 0
}
```

```weave
main = fn(args) {
	i = 1
	while i <= 20 {
		if i % 15 == 0 {
			print("FizzBuzz")
		} elif i % 3 == 0 {
			print("Fizz")
		} elif i % 5 == 0 {
			print("Buzz")
		} else {
			print(string(i))
		}
		i = i + 1
	}
	return 0
}
```

`string(...)`は値を文字列へ変換する組み込み関数です(4章で扱います)——`print`自体は数値をそのまま渡しても自動で文字列化してくれますが、ここでは`+`で文字列結合するのと同じ感覚で明示的に変換しています。

</details>
